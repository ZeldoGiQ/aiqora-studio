# AIQORA Studio (für Codex, Antigravity und andere Programme)

Lies und befolge `CLAUDE.md` in diesem Ordner. Sie gilt für dich genauso.

Die Befehle des Studios sind bei dir als Skills installiert. Sie heißen `aiqora-…`: Wo in `CLAUDE.md` oder in einem Skill `/aiqora-studio:start` steht, ist der Skill `aiqora-start` gemeint, bei `/aiqora-studio:musikvideo` der Skill `aiqora-musikvideo` und so weiter. Beim Start immer `aiqora-start`.

Findest du diese Skills nicht, liegen dieselben Anleitungen im Ordner `{{AIQORA_STUDIO_SKILLS}}`. Äußert der Nutzer einen Wunsch, der zu einer dieser Anleitungen passt (z. B. „Musikvideo“, „Bild“, „Status“), lies dort die passende `SKILL.md` und folge ihr.

Die Werkzeuge kommen von zwei Verbindungen: `aiqora` (erzeugen, kostet Guthaben) und `aiqora-local` (Ordner, Dateien, Schnitte auf diesem Rechner). Fehlen sie, sag dem Nutzer, dass das Studio in diesem Programm noch nicht eingerichtet ist.
