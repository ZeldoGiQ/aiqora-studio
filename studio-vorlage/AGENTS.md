# AIQORA Studio (für Codex)

Lies und befolge `CLAUDE.md` in diesem Ordner. Sie gilt für dich genauso.

Die Befehle des Studios liegen als Anleitungen im Ordner `{{AIQORA_STUDIO_SKILLS}}`. Wenn der Nutzer einen Wunsch äußert, der zu einer dieser Anleitungen passt (z. B. „Musikvideo“, „Bild“, „Status“), lies die passende `SKILL.md` und folge ihr. Beim Start immer `start/SKILL.md`.
