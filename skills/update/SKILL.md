---
name: update
description: AIQORA Studio auf die neueste Version bringen und sagen, was neu ist.
---

1. Dem Nutzer sagen, dass er in Claude Code `/plugin` tippt, den Marktplatz **aiqora** aktualisiert und **AIQORA Studio** aktualisiert. Alternativ, wenn der Nutzer zustimmt, im Terminal ausführen:
   `claude plugin marketplace update aiqora` und danach `claude plugin update aiqora-studio@aiqora`.
2. Danach Claude Code neu starten.
3. In zwei bis drei Sätzen sagen, was neu ist (aus den Neuigkeiten, die der AIQORA-Server meldet, sonst aus `CHANGELOG.md` des Plugins).
4. Hinweis: Neue Funktionen auf dem AIQORA-Server sind sofort da, auch ohne Update.
